**このシステム最大のリスクは、コードのバグではなく「アカウントの持ち主が卒業して誰も触れなくなること」。** この台帳を常に最新に保ち、代替わりのたびにチェックリストを実施すること。

> 記入欄が空のままの項目は「現在の担当者しか知らない」状態を意味する。**今すぐ埋めること。**

## ⚠️ GASトリガーの罠(最重要)

毎朝9時のシート同期は、Google Apps Scriptの「時間トリガー」で動いている。**時間トリガーは"設定した個人のGoogleアカウント"の所有物**であり、その人がアカウントを消したり、スプレッドシートへのアクセス権を失ったりすると、**何のエラー通知もなく同期が止まる**。

代替わり時は必ず:

1. 新しい管理者がスプレッドシートの「拡張機能 > Apps Script」を開く
2. トリガー一覧で旧管理者のトリガーを確認
3. **新管理者のアカウントで** `setupTrigger` 関数を一度実行(自分名義のトリガーが作られる)
4. 旧管理者のトリガーを削除

## シークレット(秘密の設定値)台帳

値の本体は各サービスの管理画面にだけ存在する。**場所と用途**をここで把握し、値は管理画面で直接確認する。詳細は [infrastructure.md](infrastructure.md) の台帳を参照。

| シークレット | 保管場所(正) | 対になる場所 | 失効・紛失時の再発行 |
|-------------|-------------|-------------|---------------------|
| `SHEET_SYNC_SECRET` | Cloud Run環境変数 | GASスクリプトプロパティ `APP_SYNC_TOKEN`(同じ値) | 任意の長いランダム文字列を自分で決めて、**両方に**設定し直す |
| `LINE_CHANNEL_SECRET` | Cloud Run環境変数 | LINE Developersのチャンネル基本設定(発行元) | LINE Developersで確認して設定し直す |
| `DISCORD_WEBHOOK_*` 一式 | Cloud Run環境変数 | Discordサーバー設定 → 連携サービス → ウェブフック(発行元) | DiscordでWebhookを再作成してURLを設定し直す |
| Vercelの `NEXT_PUBLIC_API_URL` | Vercel環境変数 | Cloud RunのURL(秘密ではないが消えると動かない) | Cloud RunコンソールでURLを確認して設定 |

## 代替わりチェックリスト

毎年の引き継ぎで、新旧の担当者が**一緒に**やること。所要1〜2時間。

- [ ] アカウント台帳(上表)の全8行について、新担当者がログインできることを確認し、台帳の「現在の管理者」を更新した
- [ ] GASトリガーを新担当者名義で再作成した(上記「罠」の手順)
- [ ] 翌朝、シート同期が動いたことを確認した(Discordの通知 or アプリに練習が反映されているか)
- [ ] Cloud Runの環境変数一覧のスクリーンショットを撮り、幹部の安全な場所に保存した(リビジョン事故からの復旧用)
- [ ] GCPの請求先が有効なカードに紐づいていることを確認した
- [ ] 旧担当者の個人アカウントを各サービスの管理者から外した(本人と合意の上で)
- [ ] この台帳と [operations.md](operations.md) を読み合わせ、古くなった記述を直した
